-- SUMMARY --

This very lightweight module allows additional permissions to be created
and managed through an administration form.

It uses the menu access system to allow or disallow access.

-- INSTALLATION --

* Install as usual, see http://drupal.org/node/895232 for further information.

-- CONFIGURATION --

* Define your custom permissions here (admin/people/custom_permissions).
  You can enable and as well delete the permissions which are been defined.

* Visit the permissions page (admin/people/permissions) and you can assign
  the permissions for different roles.
